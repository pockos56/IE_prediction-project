# IE_prediction

This repository contains files related to the research paper _Ionization Efficiency Prediction of Electrospray Ionization Mass Spectrometry Analytes based on Molecular Fingerprints and Cumulative Neutral Losses_ Nikolopoulos A, van Herwerden D, Turkina V, Kruve A, Baerenfaenger M, Samanipour S. ChemRxiv. 2025; doi:10.26434/chemrxiv-2025-dc9gd

#### Research paper
For more information on the model development and data handling, refer to the paper [Ionization Efficiency Prediction of Electrospray Ionization Mass Spectrometry Analytes based on Molecular Fingerprints and Cumulative Neutral Losses](https://doi.org/10.26434/chemrxiv-2025-dc9gd)

#### Julia package
For instructions and documentation on how to use the IE prediction tool, please visit the [Julia package](https://github.com/pockos56/IE_prediction.jl).
